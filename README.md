# WERT · frontend histórico

Repositório histórico do projeto WERT, preservado como referência da implementação e dos estudos de integração e publicação.

## Versão de portfólio recomendada

A documentação principal e a cópia revisada estão em [wert-frontend](https://github.com/Will-Ifes/wert-frontend). Comece por essa versão para conhecer o contexto, a arquitetura e os requisitos de execução.

## Conteúdo desta base

Frontend em Next.js, React, TypeScript e Tailwind, com páginas de autenticação, produtos, inventário e usuários.
